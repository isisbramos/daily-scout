# data/

Estado operacional da AYA: o que está rodando agora, o que vem a seguir e onde checar os números. Gerado a partir do código e dos docs vivos, não de snapshots manuais — quando este conteúdo e o código discordarem, o código vence.

- [`estado-atual.md`](estado-atual.md) — snapshot do pipeline (modelo, framework editorial, fontes, automação) a partir de `llm_config.py`, `sources_config.json` e `.github/workflows/`.
- [`roadmap.md`](roadmap.md) — o que já foi feito, o que está em execução e o que ainda não tem trabalho iniciado.
- [`fila-editorial.md`](fila-editorial.md) — fila de ajustes editoriais ainda não tratados (movido de `docs/EDITOR_NOTES.md`).
- [`metricas.md`](metricas.md) — onde medir cada métrica de `context/produto.md`, sem números reais.
