# Cloudflare lança API de busca na web para agentes de AI

Segundo HackerNews, a Cloudflare publicou uma API de busca na web voltada para agentes de AI, segundo o changelog da própria empresa destacado no HackerNews (171 pontos, 93 comentários). APIs de busca são a peça que permite a um agente consultar informação atual em vez de depender só do que estava no treino do modelo. → Desenvolvedores que constroem agentes com necessidade de dados em tempo real ganham mais uma opção de camada de retrieval para avaliar contra as alternativas já em uso.
