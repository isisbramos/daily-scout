# OpenAI transforma ferramentas de código em assistente pessoal sempre ativo, o dots

O TechCrunch reporta que a OpenAI converteu suas ferramentas de programação no dots, um assistente pessoal que fica ativo o tempo todo. A mudança indica que a empresa está reposicionando produtos originalmente voltados a desenvolvedores para um público mais amplo, de uso contínuo. Ferramentas de código costumam ter ciclos de uso intermitentes — o usuário abre, escreve, fecha —, enquanto um assistente always-on pressupõe presença constante no fluxo de trabalho. → Desenvolvedores que hoje usam as ferramentas de código da OpenAI devem acompanhar se o dots mantém as mesmas capacidades ou se vira um produto separado com outra assinatura.
- O movimento segue um padrão de mercado: empresas de AI estão migrando de ferramentas especializadas para assistentes de uso geral, que capturam mais tempo de atenção do usuário.
- Ainda não está claro no título se o dots substitui as ferramentas de código existentes ou convive com elas — vale checar a documentação oficial antes de mudar qualquer fluxo de trabalho.
- Acompanhe se a OpenAI vai divulgar preços e limites de uso do dots separadamente, o que indicaria produto novo em vez de atualização.
