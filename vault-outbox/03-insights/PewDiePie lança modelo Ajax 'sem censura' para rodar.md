# PewDiePie lança modelo Ajax 'sem censura' para rodar em PCs domésticos

Segundo post no r/artificial, o criador PewDiePie apresentou o Ajax, um modelo de AI descrito como 'sem censura' e projetado para rodar em computadores domésticos. Ele afirma ter sido banido duas vezes pela OpenAI por causa da distilação usada para construir o produto — técnica em que um modelo menor é treinado a partir das respostas de um modelo maior. O caso conecta duas tendências: criadores individuais lançando modelos próprios e a tensão com os termos de uso das APIs que servem de base para esse tipo de treinamento. → Quem treina modelos derivados de APIs comerciais deve revisar os termos de uso antes de publicar — o banimento pode inviabilizar o produto.
- Distilação é o mecanismo central da história: o modelo pequeno aprende imitando as saídas de um modelo grande, o que costuma violar termos de uso que proíbem usar as respostas para treinar concorrentes.
- Rodar em PC doméstico significa que o Ajax não depende de API paga nem de nuvem — o que muda o custo e o controle de quem usa, mas também limita o tamanho do modelo.
- Vale observar se a OpenAI vai se pronunciar oficialmente sobre o caso e se outros criadores de modelos derivados vão relatar banimentos semelhantes.
