# QGIS proíbe contribuições assistidas por IA no código do projeto

O QGIS — software open source de georreferenciamento usado por cartógrafos e analistas ambientais — decidiu banir contribuições de código geradas com assistência de IA, segundo discussão no HackerNews (295 pontos, 309 comentários). A decisão aparece como uma proposta de mudança nas diretrizes do projeto no GitHub. É um dos primeiros casos públicos de um projeto open source estabelecido fechando a porta para código gerado por LLM (modelos de IA que geram texto e código). O debate nos comentários gira em torno de rastreabilidade, direitos autorais e qualidade do código submetido. → Desenvolvedores que contribuem para projetos open source precisam verificar se o projeto aceita código assistido por IA antes de submeter pull requests.
- A discussão no HackerNews acumulou mais de 300 comentários, sinal de que a decisão divide a comunidade open source entre quem vê a medida como proteção e quem vê como barreira à produtividade.
- Projetos como QGIS têm requisitos de licenciamento e auditoria que ficam mais complexos quando o código vem de modelos treinados em bases de dados de licença incerta.
- Vale acompanhar se outros projetos open source de grande porte seguem o mesmo caminho ou se a norma continua sendo aceitar código assistido por IA sem restrição formal.
