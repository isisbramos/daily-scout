# Whistle: transcrição de fala para texto em 16,9 MB

Segundo HackerNews, o Whistle é uma ferramenta de transcrição de fala para texto que ocupa apenas 16,9 MB, segundo post com 821 pontos no HackerNews. O tamanho reduzido indica que roda localmente sem depender de servidores ou APIs pagas. → Desenvolvedores que precisam de transcrição offline ou em dispositivos com poucos recursos ganham uma alternativa leve para testar.
